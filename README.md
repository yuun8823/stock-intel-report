# stock-intel-report

自動生成される株式デイリーレポートの公開用リポジトリです。

> ⚠️ **本レポートは投資助言ではありません。**
> 掲載内容は、テクニカル指標などを用いた機械的なスクリーニングの結果を自動生成したものです。
> 特定の銘柄の売買を推奨するものではなく、内容の正確性・完全性も保証しません。
> 投資に関する判断は、ご自身の責任で行ってください。

## 内容

| パス | 内容 |
|---|---|
| `index.html` | 最新のレポート |
| `history/` | 日次レポートのアーカイブ（`YYYY-MM-DD.html`） |

## 更新について

- 平日の東京市場の大引け後に、別リポジトリのバッチ処理が自動で更新します。
- このリポジトリのファイルはすべて自動生成物です。手動で編集しても、次回の更新で上書きされます。
- 対象は日経平均株価（日経225）の構成銘柄です。

## スコアの見方

各銘柄のスコアは、RSI・移動平均乖離率・モメンタム・出来高などの指標を全銘柄で標準化し、重み付きで合成した値です。
プラスが大きいほど「買い目候補」、マイナスが大きいほど「売り目候補」として表示されます。
あくまで機械的な順位付けであり、将来の値動きを予測・保証するものではありません。
